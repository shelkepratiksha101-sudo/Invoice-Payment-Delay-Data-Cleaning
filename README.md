# Invoice Payment Delay & Cash-Flow Intelligence Platform

## Week 1: Data Cleaning and Preprocessing

### Project Overview
This project focuses on preparing an invoice dataset for analyzing payment delays and understanding customer payment behaviour. In Week 1, the main focus was on data exploration, cleaning, and preprocessing to make the dataset ready for further analysis and machine learning tasks.

### Objective
The objective of this task is to:
- Understand the structure of the invoice dataset
- Identify and handle missing values
- Check and remove duplicate records
- Detect inconsistent and incorrect data
- Prepare clean data for Exploratory Data Analysis (EDA)

### Dataset
**Dataset Name:** Global B2B Invoice & Payments Dataset

The dataset contains invoice-related information such as:
- Invoice ID
- Customer details
- Invoice Amount
- Invoice Date
- Due Date
- Payment Date
- Payment Status
- Payment Method
